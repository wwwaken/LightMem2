# Uninstall and Rollback

How to stop TokenPilot and restore your original configuration.

## Quick Rollback

During installation, TokenPilot creates `.tokenpilot.bak` backup files alongside your original configuration files. To restore your original configuration, copy each `.tokenpilot.bak` file back to its original name.
